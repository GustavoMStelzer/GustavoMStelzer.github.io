# Gustavo Stelzer — Portfólio

Sou desenvolvedor Full Stack e trabalho com C#, .NET, Angular e Oracle. Este portfólio reúne uma seleção dos projetos em que atuei, além de iniciativas pessoais.

[Acessar o portfólio](https://gustavomstelzer.github.io/)

## Projetos

- **Oracle Helper:** classe C# que criei para organizar chamadas a procedures e functions Oracle e mapear os resultados para objetos da aplicação.
- **Sistemas corporativos:** trabalhos com equipes em campo, arrecadação e conciliação, rateio de energia solar, controle de EPIs, controle de acesso e modernização de sistemas legados.
- **Ponto Crítico:** meu projeto de mini-documentários sobre tecnologia, empresas, engenharia, energia e outros temas que despertam minha curiosidade.

Os trabalhos apresentados são parte da minha experiência. Os sistemas corporativos são descritos sem expor código ou dados internos da empresa.
